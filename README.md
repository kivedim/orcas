# Orcas & Dinos

Toddler game (2–4 years) in English with read-aloud voice.

- **Orca Ocean** – steer a killer whale pod: breach, tail slap, spyhop, breathe, echolocation; fleeing fish; great white shark that bites back.
- **Egg** – hatch 6 dinosaur species (and sometimes Bibbi-Cat), tap for hearts, swipe for crashes, hugs comfort a crying dino.
- **Hide & Seek** – find the same animal twice on an open seafloor.
- **Feed** – 16 animals across sky, land and sea; 24 foods incl. silly items.
- **Sticker album** – every animal found is saved on the device.

Parent settings: hold the gear on the start screen for 2 seconds (sound, music, voice, difficulty, home-button lock).
Difficulty adapts automatically unless set by a parent.

Live: https://kivedim.github.io/orcas/

Sounds: [Kenney Interface Sounds](https://kenney.nl) (CC0).
